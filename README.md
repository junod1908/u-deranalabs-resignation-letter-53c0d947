The one-line resignation letter of an orphaned cron job: "I resign. The engineer who wrote me left in 2021. I've been serving his two weeks' notice every minute since." A deterministic Python program writes the letter to `/output/entry.txt` for make.fun's "The Funniest One-Line Resignation Letter" bounty.

## Run it

```sh
python3 main.py
```
